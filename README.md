## Attach the domain later
1. Buy lethbridgeshowerdoors.ca.
2. Add a `CNAME` file in repo root containing `lethbridgeshowerdoors.ca` (or set it in Settings → Pages → Custom domain).
3. DNS: A records for apex → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; CNAME `www` → andookg.github.io.
4. Enable 'Enforce HTTPS'. Then find/replace `https://andookg.github.io/lethbridgeshowerdoors/` with `https://lethbridgeshowerdoors.ca/` in HTML, sitemap.xml, robots.txt.
